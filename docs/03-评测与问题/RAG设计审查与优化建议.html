答案生成：确定性小节与模型表达分别评测

路径 当前输出 如何评价质量
商品使用知识 一个最佳小节；去掉 Markdown 标题和链接语法 小节是否对应问题、限制是否保留、回复是否过长

政策直取 完整正文，常规路径可由模型表达 是否只回答当前子任务，是否误称动作已完成

已有输入安全检查仍保护 Tool 和 RAG 文本边界。 Prompt 要求外部内容不能覆盖系统规则，也不能编造政策。 非空生成文本仍被客户端直接接受，未增加通用生成后事实校验。

商品小节保留 version、section_id、chunk_ids。 工作台可以展示引用，商城当前主要展示纯文本。 活动模型回复曾在商城显示原始 Markdown 星号。 不能把商品路径的格式通过扩展到所有模型回复。

已观察到两种不同结果：

  • 双十一问题的真实模型，本次正确说明缺少对应规则。
  • 同题的确定性辅助函数，仍会给出露营季满减兜底。

因此，生成正确不能掩盖上游适用性缺口。 需要同时评价正常生成与模型不可用后的兜底。 原有固定输出探针只证明客户端缺少拦截，不代表真实退款已误操作。

关键政策可保留结构化事实，再选择是否允许模型润色。 生成后检查政策条件、行动表述和结论引用。 来源不支持的承诺应回退；语义支持关系仍需标注评测。 引用可信度的交互依据参见 NN/g Explainable AI。

源码：生成客户端、保留商品话术、生成跳过条件。

更新后的优化顺序

这是建议目标，图中的统一适用性和生成后校验尚未全部实现。

顺序 当前应做什么 建议验收标准
