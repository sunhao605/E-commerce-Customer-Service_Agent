## 现在怎么用

两套进程都要看见同一个环境变量，功能才生效。默认全关，关着时商城仍走原来的整句取消和取消按钮。

| 变量 | 作用 |
|---|---|
| `CANCEL_INTENT_OBSERVE=1` | 只记录 Jev 判断，不改草稿。没有未提交办理时不调用模型。 |
| `CANCEL_INTENT_EXECUTE=1` | 允许按判断改草稿。Java 网关和 Python 都要设。 |
| `CANCEL_SCORE_MIN` | 自动取消的显式下限。不设就不自动取消。代码里没有默认 0.85。隔离验收记录值是 0.9，跑完没有改。 |
| `CANCEL_JEV_MODEL` | 默认 `jev-1.13.0`。 |
| `TYPESAFE_API_KEY` | Jev。 |
| `AGENT_OPENAI_API_KEY` / `AGENT_OPENAI_BASE_URL` / `AGENT_OPENAI_MODEL` | DeepSeek 复核，沿用项目已有配置。 |

判断入口是 `POST /cancellation/judge`。网关只在有未提交办理、且执行开关打开时才调用它。按钮点击不经过模型。

## 产品决定

这些决定已经写进实现，后面不要靠加关键词或下调 0.9 悄悄改掉。

1. 模型只做三个判断：是否已经决定停止、对象是不是当前售后、还有没有别的任务。服务端决定能不能取消。身份、草稿、版本和凭证不交给模型生成。
2. 语义和行动分开。判成停止不等于可以取消。对象没说清、还有别的任务、复核冲突、决定分不够，都不自动取消。
3. 0.85 不是商城门槛。隔离验收把 `CANCEL_SCORE_MIN` 锁成 0.9。真实模型里，“我想了想，还是不退了”的决定分是 0.51、0.38、0.41，“假如……继续退”可以到 0.53 或 0.46。下限不能降到能放过 0.38，否则会和继续退叠在一起。
4. 没有订单级退货运费来源。通用政策文案不能回答这笔订单由谁承担。条件句只保留办理，不编造承担方，也不说已经转人工。句式“要是/如果/若是/假如……运费……别退/不退/取消”在调用模型前就拦住，40 字以内。这不是取消词表。
5. 对象澄清只补对象，不是一句新的取消授权。候选用提问当时展示的顺序，只认一至十。“第一笔”在候选变化或草稿版本变化后作废。选成购买订单或另一笔时，当前售后草稿不动。
6. DeepSeek 最多复核一次，看不到 Jev 的选项和分数。Jev判断停止、对象选中当前售后但对象分低于下限时，直接让客户确认是否停止本次申请，不再追问“取消订单还是退款”。对象选中其他办理或无法确定时才追问对象。两边对停还是继续不一致，或复核失败但对象已经明确，仍出保留/取消选择卡。
7. 保留/取消选择卡的按钮是“保留当前办理”和“取消这次尚未提交的售后申请”。没有订单号时，取消按钮写成“结束这次未提交的退款办理”。凭证由服务端生成，并绑上草稿版本和订单。这张卡不能提交申请。保留不取消；当前为待提交草稿时重发带新凭证的提交确认卡，旧选择卡失效。客户尚未确定订单或尚未提供原因时仍不能提交。
8. 低分时不自动取消，也不再进普通客服。各未提交阶段统一出第7项的保留/取消选择卡；退款文案为“是否停止本次尚未提交的退款申请？”，退货文案为“是否停止本次尚未提交的退货退款申请？”。不增加“原购买订单继续保留”的解释。如果先追问对象，客户明确当前退款后仍低于决定门槛，也走同一出口，并清理已完成的对象等待。已有提交卡时新停止确认卡使原提交凭证失效；客户点保留后重新生成提交卡。保留选择写入最近对话，后续可补原来缺少的信息；点取消则结束尚未提交办理。
9. 整句“算了，不退了”等旧规则仍是模型不可用时的回退。模型明确判成继续时，旧规则不能再把这句取消掉。不继续加长自然语言关键词。
10. 草稿版本用内容变化才递增的 `draftRevision`，不用每次读取都会变的 `updatedAt`。版本变化会使旧冲突卡失效。
11. 点击保留是明确继续。等待选单且没有未决停止确认或对象澄清时，客户补纯完整订单号按办理状态直接核验并续办，不让旧取消对话覆盖补信息。客户重新表达停止仍走原取消判断；本次不扩展其他自然语言补信息。

## 不要接着做的事

- 不要把 `CANCEL_SCORE_MIN` 降到 0.5 附近去补“我想了想，还是不退了”。继续退的决定分可以落在 0.46 到 0.53。
- 不要打开真实用户流量。执行开关默认关闭。
- 不要做 P5 复合任务。真实模型还没有走出冲突卡，复合顺序没有验收。
- 不要为退货运费造一个政策工具。订单级来源不存在，这一支只保留办理。
- 不要把对象确认句“结束这次”当成新的取消授权。它只补对象，原先决定分不够时仍不取消。
- 高分同错仍在。两边都把对象判成当前售后，而且三项分数都高于下限时，仍会直接取消。
