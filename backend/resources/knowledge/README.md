- 商品名称、券结构和活动会场来自项目源码。金额样例或商品种子不能代替实时业务查询；商品的价格、库存、规格、活动资格、本人持券和订单状态仍查工具。
- 客服问法与说明中的案例是编写的模拟素材，没有伪装成真实客户数据。未查到的性能参数、优惠条件、费用、质保期限和到账时间保持未知。
- REI 与 deuter 的资料只用于少量通用使用知识，不作为荒野户外产品检测、售后或权益承诺的依据。

通用活动文档中保留“满 300 减 40 可与平台会员券叠加”的既有规则；当前商城结算主要按具体商品活动价和会员条件计价。本轮没有实现通用满减与用户券的完整扣减组合，不能拿文档中的叠加说明保证实际结算已按该组合执行。
