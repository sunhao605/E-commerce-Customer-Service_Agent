# 意图识别与证据检索：实现与验收记录

本次按用户已认可的 [产品规划](../../../docs/02-产品设计/02-意图与政策咨询/意图识别与证据检索产品需求规划.md)实施代码；起始日期 2026-10-13，跨日收尾。状态：**代码与隔离检查完成，小组真实路由探针通过；未主动重启日常服务，未做正式留存集或页面验收。**

## 1. 最终行为

- 现有路由模型同一次返回主意图与适用证据字段，不新增 Jev 或第二个证据分类请求。
- 商品字段严格校验：布尔与 null 分开；缺字段、越界域、额外工具／策略等不能静默接受。
- `RoutePlan` 根据受控知识域生成检索策略，商品执行消费同一结果。有效模型结果不被原关键词覆盖，关键词仅为模型故障兜底。
- 商品事实、商品指南、活动政策可以组合。独立且证据充分的知识可在商品待选／查询失败时回答，仍明确价格未知，不以通用政策承诺具体权益适用。
- 券叠加缺组合对象时先澄清。两个缺口可以分别补充；商品选款后只继续未完成需求，价格已回答后补优惠组合不重复查价。
- 各知识域分别记录引用、检索与状态，工作台新增事实需求、知识域与策略显示。
- 新增路由实际耗时与 token usage；模型已调用但响应无效时仍计一次调用，未提供 usage 时不假定为零。
- 商品工具现仅核实价格、库存和活动；所问承重、温标等参数未核实时明确说明，不从指南补数值。
- 页面只有商品编号而缺类别时，代码先核对该对象，仍不把读到的价格库存当成指南问题答案；页面新对象优先于旧历史，身份读取失败不套旧指南。失败指向作为未核验线索保留，不冒充已选对象。
- 历史与咨询状态进入新增路由上下文前复用脱敏。现有商品对象、资格、取消、确认和审批边界维持。
