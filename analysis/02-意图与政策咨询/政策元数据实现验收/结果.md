# 政策元数据 MVP：实现与隔离验收

日期：2026-10-14。按[规划 v0.2](../../../docs/02-产品设计/02-意图与政策咨询/政策元数据MVP产品需求规划.md)实施。**代码、确定性工程检查与隔离工作台页面检查完成；未发布到日常服务。**

## 最终行为与业务边界

- 六份材料统一采用五项核心字段，状态设为本演示项目的 `published`，版本 `2026-10-14.2`。用户指定的区间为上海时间 `[2025-01-01T00:00:00+08:00, 2028-01-01T00:00:00+08:00)`，含2027年12月31日整日。正文、身份与知识域保留。
- 整批读取、字段和时区校验、ID去重及版本／内容检查通过后，才暴露完整快照。校验失败时新进程启动失败；没有已发布或当前有效材料是正常的无依据状态，不需要为全空材料调用 Embedding。
- 每条聊天请求用服务端的同一判断时刻。向量、关键词、指定文件和申请附加引用执行同一状态／时间准入。有效政策不代表客户具有优惠或退款资格；业务工具、客户确认和审核保持原职责。
- 五份混合索引加一份指定退货共同决定知识快照身份。内部索引 reset 只重建当前快照；磁盘编辑不会让旧索引搭配新正文。普通完整重启才加载新批次。
- 检索缓存包含当前可用政策集合身份，命中后再核对引用身份、版本和状态。跨过开始或截止时刻后重新取证，包括此前空结果；无需新增远程时钟、TTL平台或模型调用。
- 发票最终答案缓存读写停用，底层检索缓存保留。计划显示改为 `hybrid/document`，成本不再展示未使用的旧缓存键。发票兜底采用实际政策正文，避免引用变了却仍回复旧硬编码文本；固定检索问句和FAQ子任务缺口仍保留。
- 失效政策不提供给最终模型，不生成有效引用。活动规则不可用时保留已核实价格，说明未知；售后附加政策不可用不会放宽业务资格或授权。工作台展示状态、版本、期限、判断时刻、快照与阻断原因，商城不新增页面。

执行代码：[统一加载与准入](../../../backend/retrieval/documents.py)、[索引与缓存](../../../backend/retrieval/hybrid_retrieval.py)、[指定政策与发票](../../../backend/retrieval/knowledge.py)、[编排入口](../../../backend/agent/customer_service_agent.py)。没有新增依赖或修改Java、数据库、模型配置和取消执行开关。

## 发布与回滚

1. 保存整批六份文件及 `release-manifest.json`，修改正文或治理信息时提高对应 `version`。
2. 在新进程离线校验，保留原清单作比较；相同版本但内容哈希变化会阻断。通过后由维护者保留返回的 `snapshot.manifest` 为新批次清单，不把更新清单作为规避版本检查的方法。
3. 完整重启日常进程，核对health的六份 `governed_files`、快照与索引，再检查一条混合及一条直取。撤回也需要这一步，不承诺热更新或零停机。
4. 回滚时选择已保存、元数据合法且可采用的完整批次，重新校验并完整重启。日期过滤仍生效；已撤回材料必须重新确认，不能自动恢复。

当前[版本清单](../../../backend/resources/knowledge/release-manifest.json)是准备批次的内容记录，不是已部署证明。[迁移前材料](knowledge-before)仅用于比较，其缺少发布状态，不能直接当通过新准入校验的回滚批次。

离线复跑：

```bash
env PYTHONPATH=backend AGENT_COURSE_DISABLE_LLM=1 AGENT_COURSE_OFFLINE_FACTS=1 AGENT_COURSE_OFFLINE_RAG=1 .venv/bin/python -m unittest discover -s backend/tests -v
```

批次校验（不会创建索引或调用模型）：

```bash
env PYTHONPATH=backend .venv/bin/python -c 'from retrieval.documents import get_knowledge_snapshot; s = get_knowledge_snapshot(); print(s.version); print(s.manifest)'
```

隔离浏览器使用18800／14173端口，在线模型禁用、事实为演示数据，商城业务入口设为不可达地址；临时后端、前端和页面已关闭。没有日常服务重启、业务API查询或资金／售后提交。日常运行版本未核验；真实语义质量、外部Embedding、复杂适用范围、历史政策与FAQ问答化未由这些成绩证明。
