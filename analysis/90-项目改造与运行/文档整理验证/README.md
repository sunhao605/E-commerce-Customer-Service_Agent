# 文档整理验证

2026-10-12。这里只核验目录迁移、引用和材料保全，不代表新增业务功能验收。

| 文件 | 用途 |
|---|---|
| [check_documents.py](check_documents.py) | 只读检查当前目录入口、本地文档链接、Python 脚本语法与软链接 |
| [result.json](result.json) | 本轮检查结果、文件保全统计与检查边界 |
| [路径迁移清单.json](路径迁移清单.json) | 旧文件或目录 → 新位置，目录项覆盖其全部内部文件 |

从项目根目录复查当前文档：

```bash
python3 analysis/90-项目改造与运行/文档整理验证/check_documents.py
```

不访问网络、不调用模型、不启动服务、不写业务表。URL 可打开性、Markdown 标题锚点、历史源码行号和业务脚本运行结果未纳入这次检查。外部参考副本中缺失的原项目链接单独报告。
