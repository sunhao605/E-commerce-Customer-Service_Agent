# 荒野户外露营季活动客服知识

## 1. 本文件说明什么

本文是项目演示知识，保留既有满减和会员券叠加规则，补充活动范围、价格差异和异常咨询的处理方法。具体活动是否正在进行、哪件商品参与、活动价、会员门槛、优惠券状态和最终金额需要查询活动及结算数据。

本轮文档更新时间不代表活动开始时间；政策 ID 使用 camping_season 标识露营季，不表示固定月份。本文不设一个覆盖全部商品的永久活动周期，不提供未发布的双十一、黑五或隐藏券规则。

活动知识用于解释已经取得的优惠条件。它不能代替库存、价格、本人持券和订单金额查询，也不构成“所有商品都参与”或“现在一定是最低价”的承诺。

## 2. 先识别具体活动与商品

顾客说“这次活动能不能叠”，应先确认活动名称、所问商品和券。仅提“优惠”“满减”不足以确定是哪场活动。顾客明确说“双十一”时，不能把它改成露营季并回答当前满减规则。

顾客从商品详情页进入，页面关联商品可以帮助确认对象；顾客随后明确换了商品，需以新对象为准。多个同类商品都有活动时，展示候选，让顾客选择；不能自动采用第一款的活动条件。

同一会场不同商品可能有不同会员门槛。活动宣传中的“营地装备精选”不等于每件营地装备都参加；商品已下架、活动过期或库存不足也应分别说明。

## 3. 项目现有会场及条件类型

现有商品活动数据包括以下会场。名称来自源码种子，下面不列静态活动价，避免顾客把旧数据当当前成交价。

| 会场名称 | 涉及商品举例 | 解释时必须核对 |
|---|---|---|
| 营地家具会员会场 | 折叠椅、折叠桌、野餐垫 | 各商品是否要求山友会员，是否有本人可用券 |
| 帐篷天幕精选会场 | 四人帐篷、天幕、收纳柜、防水袋 | 具体商品活动价和会员条件，不能复制别款价格 |
| 营地装备精选会场 | 收纳车、大型帐篷、背包、定制标识 | 商品参与情况及条件；定制限制不由活动取消 |
| 露营配件会员会场 | 营地灯、炊具套装 | 是否要求行者及以上，是否属于该品类 |
| 徒步装备满减会场 | 登山杖、睡袋 | 具体型号条件和当前价格；不承诺全徒步品类通用 |

“会员专享价”“活动直降”“品类券”和“满减”是不同条件类型。客服应先解释查询到的是哪一种，再回答能否同时使用。不能把商品的活动价、宣传面额和通用满减全部叠在一起得出最低价。

## 4. 满 300 减 40 与叠加边界

现有通用政策说明：符合露营季活动条件时，满 300 减 40 可以与平台会员券叠加；同类型满减券不能重复叠加。它没有定义“每满 300 减 40”、所有订单无限次参加、其他券种一律兼容等规则，不应补出这些结论。

是否达到 300 元，需要核对这笔订单的计价和参与范围。若顾客只是把购物车中所有标价相加，尚不能证明全部金额计入门槛。运费、未选中的商品、其他活动商品是否计入，不在这份短政策的已确认范围内。

只解释门槛的模拟算例：假设活动确认计入的金额为 299 元，则未达到 300；确认为 300 元或 398 元，则达到这个门槛。这里只说明达到门槛，不表示当前结算已经扣除 40 元，更不计算未知会员券的最终金额。

顾客问满 600 是否减 80，不能根据满 300 减 40 自行推导“每满”。顾客问两张满减券是否可一起使用，应按同类限制解释；若券类型不同，要取得这两张券及当前活动的具体组合规则。

## 5. 页面价格、活动价格与成交价格

商品页面可能展示基础价和有条件的活动价。符合账号等级与活动条件后，结算才能确定实际单价；商品详情页出现活动信息不等于每位顾客都能享受。当前订单金额还可能受数量、商品选择和下单时状态影响。

顾客说“页面写 529，结算却是 599”，先确认商品、活动时间、会员条件和账号。这里的金额只是项目旧种子中可出现的示例，不是当前报价。如果未查到实时数据，应说明无法确认差异原因，不能默认顾客未登录或系统出错。

顾客说“昨天有优惠，今天没有”，需比较两个时间点的证据。旧截图能说明当时看到的内容，但不能自动证明现在的活动应恢复。客服不凭截图承诺改价，也不引导顾客先付款再保证返差价。

没有现成的保价条款和执行能力时，不能说“七天内降价都退差价”。价格差异可以记录待核验，但不能用普通退款流程补造保价申请。

## 6. 活动异常的核验顺序

先定位具体商品和活动，再确认时间、账号等级、参与范围、券状态与结算明细。顾客提供的信息与系统返回不同，保留双方证据；一次查询失败不等于活动不存在。

- 活动查到但已过期：解释该活动时间，不把过期活动当仍有效。
- 商品没有对应活动：说明没有查到这个商品的活动，不扩展成商城从未举办该活动。
- 库存为零：说明查询到的库存情况，不用活动规则保证一定补货。
- 价格或条件字段缺失：说明缺哪个字段，不能靠其他商品补齐。
- 服务读取失败：说明暂时不能确认，给出重试或查看结算的路径，不虚构折扣。
- 不明活动名或“隐藏券”：说明没有对应已发布证据，请顾客提供规则，不套用露营季。

## 7. 退款、退货与优惠之间的关系

活动参与不改变订单是否本人、是否已支付、是否已发货和是否支持七天无理由等售后前提。不能以“特价”一词直接拒绝所有售后，也不能说参加露营季的商品都可无理由退。

退款金额应核对订单实际支付与已退款情况，不按当前标价或宣传满减推算。客服没有资金结果时，不能说“优惠已经重新分摊”“返券已经完成”或“差价已补给你”。部分退款、优惠分摊和返券不在当前自动办理承诺内。

顾客问“退一把椅子，另一件就不满 300 了怎么办”，这是部分退货与优惠分摊问题，需要单独规则和执行支持。当前自助整单流程不能代替，先说明范围，再引导后续核验，不承诺具体扣款或返券。

## 8. 常见客服场景

以下为模拟问法，分别检验活动对象、账号条件、门槛和跨文档证据。

| 顾客问题 | 正确的处理方向 | 不应给出的结论 |
|---|---|---|
| “露营季满减能叠我的山友券吗？” | 取得具体券，结合通用叠加规则和券条件 | 任意券都能叠加 |
| “双十一也和这次一样吗？” | 明确缺少双十一政策，不能沿用露营季 | 双十一也是满 300 减 40 |
| “三件商品加起来超过 300，怎么不减？” | 核对参与范围及结算金额 | 一定是平台漏减，已补偿 |
| “满 600 是不是自动减 80？” | 说明现有规则没有给出每满口径 | 肯定可以累计减 |
| “朋友看到低价，我怎么没有？” | 核对商品、时间、等级和持券差异 | 把朋友的权益直接移给你 |
| “券过期了，活动没结束就还能用吧？” | 分开核验活动时间与券时间 | 活动有效就使过期券恢复 |
| “退款后券和满减都返给我吧？” | 查询退款和返券规则，明确能力缺口 | 所有优惠均原样恢复 |
| “我只退其中一件，剩下价格不要变” | 说明部分退款和分摊未自动支持 | 已按顾客要求冻结剩余价格 |

## 9. 关联材料与证据冲突

会员身份与券规则见 [会员知识](member_coupon_policy.md)。商品使用、规格缺失和配件核验见 [商品指南](product_knowledge.md)。退款与退货分别见 [未发货退款政策](after_sale_policy.md) 和 [签收后退货政策](received_return_policy.md)。

出现规则冲突时，先说明冲突内容和来源，不把两个条件拼成一条新政策。具体订单判断需要对应活动、券与订单证据；缺少有效时间或对象时暂不承诺资格。顾客咨询优惠不会自动触发领券、改价、创建订单或退款。
